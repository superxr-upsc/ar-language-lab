# 🌍 AR Language Lab

**AR Language Lab** is an educational mobile application built with **Unity** and **AR Foundation**, designed to make foreign language learning more engaging through Augmented Reality.

Instead of memorizing vocabulary from textbooks or flashcards, learners interact with virtual 3D objects placed in the real world. By completing interactive tasks, users build associations between words, objects, and actions, making the learning process more intuitive and memorable.

# 🎮 Learning Workflow

The learning process consists of several stages.

### 1. Object Discovery

The learner scans physical AR markers using the mobile device.

Each marker represents a real-world object, for example:

* 📖 Book
* 🍎 Apple
* ☕ Cup
* 📱 Phone
* 🪑 Chair

After recognition, a detailed 3D object appears in Augmented Reality together with its translation into the selected language.

This stage allows the learner to build visual associations between objects and vocabulary.

---

### 2. Interactive Exercises

After becoming familiar with the objects, the learner starts completing educational tasks.

Examples include:

**Place the apple next to the book.**

**Find the cup.**

**Arrange the objects from smallest to largest.**

**Move the phone onto the table.**

Another exercise type presents an incomplete sentence where one object is missing.

Example:

> I drink coffee from a ______.

The learner must place the correct virtual object into the empty space.

Every completed task is instantly validated, providing immediate visual feedback.

---

### 3. Progressive Difficulty

As the learner progresses, the application introduces more complex challenges:

* multiple objects
* more complex instructions
* object ordering
* contextual vocabulary
* sentence completion
* memory-based exercises

This gradual progression encourages natural language acquisition rather than simple memorization.

---

# 🧠 Why Augmented Reality?

Traditional vocabulary learning often relies on static images or plain text.

AR Language Lab transforms the learning experience by allowing users to interact with virtual objects as if they were physically present.

The combination of movement, visual interaction, and contextual tasks creates stronger cognitive associations and increases learner engagement.

---

# 🔧 Content-Driven Architecture

One of the project's key goals is flexibility.

The application is designed so that educational content can evolve independently from the application itself.

This means new content can be added without publishing a new version of the application.

Possible updates include:

* new languages
* new vocabulary packs
* additional lessons
* new exercise types based on existing mechanics
* modified lesson configurations
* difficulty adjustments

This makes the application suitable for long-term educational use while minimizing maintenance costs.
